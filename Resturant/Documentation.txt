# 🍽️ Foodie's Delight Restaurant Website

A simple multi-page restaurant website built using only Basic HTML. This project was created as a beginner-friendly mini project to practice basic HTML concepts such as headings, paragraphs, links, images, lists, tables, and multimedia.

## 📌 Project Overview

**Foodie's Delight** is an imaginary Indian restaurant website that allows users to:

* Learn about the restaurant
* View the menu and prices
* Browse food images
* Find contact information and opening hours

The project does not use CSS or JavaScript. The main purpose is to strengthen HTML fundamentals and understand how multi-page websites work.

---

## 📄 Pages Description

### 1. Home Page (index.html)

Contains:

* Restaurant name
* Welcome message
* Navigation links
* Restaurant image
* Today's special dishes

**HTML concepts used:**

* Headings (`<h1>` to `<h3>`)
* Paragraphs (`<p>`)
* Links (`<a>`)
* Images (`<img>`)
* Lists (`<ul>`)

---

### 2. Menu Page (menu.html)

Contains:

* Food categories
* Dish names
* Prices

**HTML concepts used:**

* Headings
* Tables (`<table>`)
* Lists (`<ul>`)

---

### 3. Gallery Page (gallery.html)

Contains:

* Images of Indian dishes

**HTML concepts used:**

* Images (`<img>`)

* Paragraphs

---

### 4. Contact Page (contact.html)

Contains:
